홈택스 수임동의·해임, 대표님이 직접 하시면 3분이면 끝납니다

공인회계사 이규범｜2026년 11월
결론: 기장을 맡기실 때 가장 먼저 필요한 절차가 홈택스 「수임동의」입니다. 동의가 끝나야 저희가 신고 내역·세금계산서·사업용 카드 내역을 직접 조회할 수 있고, 대표님께 자료를 따로 요청드리는 일이 크게 줄어듭니다.

수임동의란

세무대리인이 홈택스에서 대표님 사업자의 세무 정보를 조회하고 신고를 대신할 수 있도록, 대표님이 직접 승인하는 절차입니다. 세무대리인이 먼저 사업자 정보로 수임을 신청하면, 대표님은 홈택스에서 그 신청을 확인하고 동의만 누르시면 됩니다.

동의 방법 (5단계)

홈택스 로그인›세무대리·납세관리›나의 세무대리·납세관리인›세무대리 수임동의
  1. 홈택스(hometax.go.kr)에 로그인합니다. 법인은 법인 공동인증서로 로그인하셔야 합니다.
  2. 상단 메뉴 오른쪽의 세무대리·납세관리를 누릅니다.
  3. 나의 세무대리·납세관리인을 누릅니다.
  4. 세무대리 수임동의를 누릅니다.
  5. 신청한 세무대리인 정보를 확인하고 체크한 뒤 동의하기를 누르면 끝입니다.

정보제공 범위는 「해당 사업장」이 기본입니다. 개인사업자가 다른 소득까지 함께 맡기실 때만 「타소득 포함」을 고르시면 됩니다.

세무대리인을 바꾸실 때 (해임)

이미 다른 세무대리인이 등록되어 있으면 새 수임이 되지 않습니다. 기존 대리인을 먼저 해임하신 뒤 새로 동의하시면 됩니다.

홈택스 로그인›세무대리·납세관리›나의 세무대리·납세관리인›세무대리인 해임
  1. 홈택스 로그인 후 세무대리·납세관리를 누릅니다.
  2. 나의 세무대리·납세관리인 → 세무대리인 해임을 누릅니다.
  3. 해임 사유(폐업·세무대리인 변경·기타)를 고르고 해임하기를 누릅니다.
주의: 해임한 당일에는 같은 세무대리인에게 다시 수임동의를 할 수 없습니다. 「기존 대리인 해임 → 새 세무대리인 동의」 순서로 진행해 주세요.

동의 후, 저희가 먼저 확인하는 것

동의가 끝나면 직전 연도 신고 내역, 전자세금계산서·현금영수증, 사업용 카드 사용 내역, 원천세 신고 내역을 저희가 직접 조회합니다. 대표님께는 홈택스에 나오지 않는 몇 가지(통장 거래내역, 미등록 카드 여부 등)만 한 번에 정리해 여쭙니다. 확인한 내용은 「이렇게 파악했는데 맞으신가요?」 형식으로 보내 드리니, 맞는지만 봐 주시면 됩니다.
